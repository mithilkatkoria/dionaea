DETECTOR PERFORMANCESIMULATED — NOT EXPERIMENTAL BIOLOGY

A true detection is the first alert within each labelled episode. Extra alerts—including repeated ones inside the same episode—are false alarms. Delay is measured from the episode start.

02 / THE METHODHOW THE EXPERIMENT WORKS

Four algorithms.
One fair comparison.

01

Single event

Raise an alarm for any observed event. Fast, simple, often noisy.

trigger if xₜ = 1
02

Timed pair

Wait for two events sufficiently close in time; an explicitly flytrap-inspired baseline.

two events within Δt
03

Sliding count

Count recent events in a rolling window and compare against a fixed minimum.

count(window) ≥ k
04

Leaky evidence

Accumulate evidence while retaining only a fraction of the preceding state.

THE ACTUAL BIOLOGY

Venus flytraps use mechanosensation, electrical signalling and calcium dynamics. This is a conceptual abstraction, not a physiological simulator.

THE EXPERIMENTAL LIMIT

Synthetic binary events are deliberately simple. Performance here does not establish clinical, industrial or general real-world suitability.

03 / REPRODUCIBILITYBEYOND A SINGLE EXAMPLE

Don't trust
one lucky seed.

One simulation can be misleading. The accompanying Python experiment selects parameters on 15 training seeds, freezes them, then evaluates all methods on 40 unseen seeds in each of four conditions.

Try python -m dionaea.benchmark to regenerate the results. Edit the cost of false alarms and see whether the ranking changes.
